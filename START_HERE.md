# FE Civil Prep — Balanced Question Cards

## Publish (Mac or PC — no Terminal)
1. Extract `FE_Civil_Prep_Balanced_Question_Cards_GitHub.zip`.
2. Create a **new GitHub repository**, for example `FE_Civil_Prep_Balanced`, or replace the files of an existing website repository.
3. Click **Add file → Upload files**, and select **all the extracted website files**. Do not upload the outer ZIP directly.
4. Keep `index.html`, `app.js`, the six source PDFs and all `.js` data files at the **repository root**.
5. Commit, then select **Settings → Pages → Deploy from a branch → main → /(root)**.
6. Open your repository's GitHub Pages URL and test Question 1, a timed session, a companion exam, and **View original question**.

There are no ZIP files inside the download. All source PDFs are already included. The original reference pages render through Mozilla PDF.js loaded over HTTPS, so the browser must be online.

## How to use the new study interface
- **Question library:** search/filter by book, subject, subtopic and review status.
- **Practice questions:** select the available answer-key pool or the manually checked pool, then choose subject, subtopic, source, and session size. All-subject sessions rotate topics.
- **One question per screen:** select an answer, choose **Submit answer**, then **View solution**, then **Next question**. In timed sessions the solutions become accessible after session submission.
- **Original reference:** select **View original question** or **View original solution** only when you need to check the exact printed equations, diagrams or tables. They no longer appear as the main default screen.
- **Timed exams:** 20/60 and 110/320 minute practice modes, with source-key scores explicitly marked provisional.

## What has and has not been verified
The database indexes 2,294 original source positions from the two books and the four Learnova practice exams. Only 91 entries are manually checked; 791 more use provisional publisher-key comparison; 1,412 are review-only. Of the 440 companion exam entries, 221 have an exact normalized text match to a main Learnova question and therefore inherit its subject label; the other 219 are **unclassified** rather than assigned a guessed topic. The site includes 65 redrawn diagram cards. The six original PDFs contain the remaining printed diagrams and sketches and can be viewed through an optional reference.

The PDF/source solutions have not all been independently solved. The website is not NCEES-affiliated or validated as equivalent to the real FE exam.
