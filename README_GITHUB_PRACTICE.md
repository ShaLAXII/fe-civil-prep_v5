# FE Civil Prep — Balanced Practice Edition

## What changed
- One native question card per screen; original PDF pages are **optional** via `View original question` and `View original solution`.
- New question flow: select answer → **Submit answer** → **View solution** → **Next question**. For review-only items, grading is disabled.
- Subject and subtopic filters for the question library and custom study sets; source filters also included.
- Mixed practice sessions rotate subjects and subtopics where the available question bank permits it. This is not NCEES blueprint weighting.
- Identical companion-exam text matches are mapped to their main-book subjects (exact normalized text matching only). Unmatched companion-exam topics remain unclassified, rather than guessed.
- Retains the original PDF question and worked-solution pages, 65 existing illustrated cards, timed sessions, bookmarks, progress, and reports.

## Publish
Unzip the package. Upload all extracted files to the root of a GitHub Pages repository (including six source PDFs). Select Settings > Pages > Deploy from a branch > main > /(root). There are no nested ZIPs. No Terminal is needed. The largest file is under GitHub's browser upload limit. The site uses the Mozilla PDF.js CDN for optional original-page rendering, so an internet connection is required for that feature.

## Scope and limitations
**2,294 indexed source positions, not 2,294 independently verified questions.** There are 91 manually checked items; other items may be ungraded or graded provisionally against publisher keys. Original figures can be viewed in the optional source reference; only 65 cards have independent vector diagrams. Do not upload the books to a public site unless your written publisher permissions cover online redistribution.
